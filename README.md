A deterministic Python 3.13 program (standard library only, offline) that draws one open passport spread for the invented Republic of Talveria as a single 1024x640 PNG: a data page for holder Elin Mara Varkova (passport TV1234567, issued 12 Jun 2023 in Vornak) with portrait and machine-readable strip, and a visas page with matching Kessaria and Drenovia entry/exit stamps, a conditions-of-entry box, and a departure-tax stamp.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`, then check `out/entry.png` (1024x640, ~31 KB).
